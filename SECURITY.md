# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.0.x   | :white_check_mark: |
| < 7.0   | :x:                |

## Reporting Security Vulnerabilities

The QuantyCoin core development team takes security and consensus safety extremely seriously.

If you find a security vulnerability, bug in cryptographic math, RPC overflow, or P2P denial of service:
1. **DO NOT** open a public issue on GitHub.
2. Email full technical details and proof-of-concept steps to:
   **timfromhcs@gmail.com**
3. We will acknowledge receipt within 24 hours and provide an estimated patch timeline.
4. Vulnerability disclosures will be coordinated responsibly with CVE allocation and patch releases.

Thank you for helping keep the QuantyCoin network secure and sovereign.
