# Getting Support for QuantyCoin

Welcome to the QuantyCoin community! If you have questions, need assistance running a node, mining, or developing on the protocol, use the resources below.

---

## 1. Documentation & Guides

Before opening an issue, check the official documentation:
- **[User Guide](docs/USER_GUIDE.md)**: Node installation, wallet setup, and transacting.
- **[Miner Guide](docs/MINER_GUIDE.md)**: Solo mining and Stratum V1 mining pool connectivity.
- **[Developer Guide](docs/DEVELOPER_GUIDE.md)**: Architecture, RPC endpoints, and testing.
- **[Trust Center](TRUST.md)**: Verification guides, threat model, and reproducibility.

---

## 2. GitHub Issues & Discussions

- **Bug Reports**: If you find an unexpected error or software defect, please open a [Bug Report](https://github.com/timfromhcs/QuantyCoin/issues/new?template=bug.yml). Include your OS, Python version, error logs, and reproduction steps.
- **Feature Requests**: To suggest enhancements or architectural proposals, open a [Feature Request](https://github.com/timfromhcs/QuantyCoin/issues/new?template=feature_request.yml).
- **General Questions**: For setup guidance or community discussions, participate in GitHub Discussions or Issues.

---

## 3. Security Vulnerabilities

> [!IMPORTANT]
> **Do not report security vulnerabilities in public GitHub issues.**

Please follow the Coordinated Vulnerability Disclosure process outlined in **[SECURITY.md](SECURITY.md)** to report consensus-breaking bugs, remote code execution risks, or cryptographic flaws securely.

---

## 4. Community Standards

All community members and contributors are expected to adhere to our **[Code of Conduct](CODE_OF_CONDUCT.md)**.
